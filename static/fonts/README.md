# Bundled fonts

Noto Sans, Noto Sans Tamil, Noto Sans Devanagari and Noto Sans Arabic (Regular + Bold), © The Noto Project
Authors, licensed under the SIL Open Font License 1.1 (see `OFL.txt`). Source: https://github.com/notofonts

They are bundled so that ID cards, PDFs and PNG exports render Tamil, Hindi and Arabic correctly without
depending on a third-party font CDN or on fonts installed on the viewer's device.
